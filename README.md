# Git and GitHub Assignment

## Project Overview
This project demonstrates basic Git and GitHub usage for version control and sharing work publicly. It includes a Python script that creates and displays a sample dataset.

## Objectives
- Create and manage a Git repository.
- Practice adding and committing files.
- Share code through a public GitHub repository.
- Use Markdown to document a project.

## Project Files
- `sample_data.py`: Creates and displays a sample student dataset using pandas.
- `README.md`: Describes the project and how to use it.

## Dataset Description
The fictional dataset contains student names, ages, study hours, and scores.

## Technologies Used
- Python
- Pandas
- Git
- GitHub
- Markdown

## How to Run
Install pandas using `python -m pip install pandas`, then run `python sample_data.py`.
